Watermark

Un marchio, molti formati. Aggiungi testo, un logo o una pagina PDF a immagini e documenti. Tutto resta nel tuo browser.

Impostazioni watermark

1. Aggiungi i file

La selezione vale per tutti i PDF. Puoi sostituirla per ciascun file qui sotto. I numeri oltre la fine del documento vengono ignorati; un PDF senza pagine corrispondenti non viene esportato. Le immagini vengono sempre marcate.

2. Scegli il marchio

Per un logo senza sfondo usa un PNG trasparente. Il marchio PDF viene convertito in immagine; il bianco disegnato nel file resta bianco.

3. Posizione e dimensione

X e Y indicano il centro del marchio, dall’angolo in alto a sinistra. 50% / 50% = centro pagina.

Le proporzioni del marchio sono conservate. Vicino ai bordi la posizione viene limitata per mantenerlo interamente nella pagina; se troppo alto, il marchio viene ridotto.

4. Controlla e applica

Controlla una pagina prima di esportare.

File pronti

Scarica ogni file dal suo nome oppure raccogli i risultati in uno ZIP. I PDF mantengono le pagine originali: viene aggiunto soltanto il marchio. Le immagini mantengono le dimensioni in pixel: JPEG in JPEG, PNG e WebP in PNG. I metadati delle immagini non vengono trasferiti.
