File Renamer

Rename multiple files with find and replace, case conversion, direct editing, or a two-column CSV. Everything stays in your browser.

2. Rename

The two modes are alternatives. Uploaded files stay available and each mode keeps its own preview.

Each application starts from the original name. Longer find matches have priority.

Prefixes, suffixes and sequences

The sequence follows the order of the table and numbers only selected files. File extensions are unchanged.

Find/replace, letter case, prefixes, suffixes and numbering are applied together, always to the original name. You can also edit names manually in the final table.

The table does not replace uploaded files. It can contain multiple columns: choose which ones to use. Names must include extensions; files not listed in the table keep their original name.
