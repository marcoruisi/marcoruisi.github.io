Rinomina file

Rinomina più file tramite Trova e Sostituisci, maiuscole/minuscole, modifica diretta o CSV a due colonne. Tutto resta nel browser.

1. Carica file

2. Rinomina

Le due modalità sono alternative. I file caricati restano disponibili e ogni modalità conserva la propria anteprima.

Le regole si applicano simultaneamente al nome originale: le corrispondenze più lunghe hanno priorità.

Prefissi, suffissi e sequenze

La sequenza segue l’ordine della tabella e numera solo i file selezionati. Le estensioni restano invariate.

Trova/Sostituisci, maiuscole/minuscole, prefissi, suffissi e numerazione si applicano insieme, sempre al nome originale. Puoi anche modificare a mano i nomi nella tabella finale.

La tabella non sostituisce i file caricati. Può avere più colonne: scegli quelle da usare. Le righe incomplete vengono ignorate e conteggiate. I nomi dei file devono includere l’estensione; i file non presenti nella tabella mantengono il nome originale.

3. Anteprima ed esportazione

Le estensioni sono protette. Modifica il nome senza estensione nella colonna destra. Correggi duplicati e nomi non validi prima di scaricare.
