MRC Uploader

Una utility amministrativa WordPress per gestire file sotto uploads, importare dati CSV e modificare file sorgente con backup.

Cosa fa

  • Creazione e gestione di cartelle e file nell’area uploads di WordPress.
  • Upload, rinomina, eliminazione e preferiti.
  • Import CSV singolo/multiplo e lettura di righe da una sorgente Google Sheet.
  • File editor integrato con backup e sostituzione atomica.

SU RICHIESTA

Poiché scrive sul filesystem e include operazioni amministrative, permessi e confinamento dei percorsi vanno verificati sull’installazione di destinazione.

Se pensi che possa essere adatto al tuo progetto, descrivimi il caso d’uso. Verifico la versione esistente e, se necessario, propongo finalizzazione o adattamento come lavoro professionale.
