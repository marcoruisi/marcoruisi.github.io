La prima riga contiene le intestazioni. Separatori riconosciuti automaticamente: tab, virgola, punto e virgola, barra verticale.

2. Filtra le righe

Filtri per colonna

Tra filtri diversi vale E. In uno stesso campo separa più valori con | per usare OPPURE. La ricerca ignora maiuscole e accenti.

3. Prepara le colonne di output

Deseleziona per escludere, usa ↑ ↓ per spostare e modifica il nome nell’output. Le colonne escluse restano filtrabili.

4. Risultati

I tuoi dati restano tuoi

I file e gli elenchi incollati sono elaborati nel browser: non vengono caricati sui server MRC. Se importi da un link pubblico, il browser contatta direttamente il sito che ospita il CSV.
