Elenca file

Elenca i file di cartelle e sottocartelle con profondità configurabile. Scarica percorsi, dimensioni e ultima modifica in CSV o TXT.

1. Scegli la profondità e la cartella

0 = solo file nella cartella principale; 1 = anche le sottocartelle dirette. Dopo una modifica premi Scansiona di nuovo.

Trascina qui una cartella

Legge soltanto nomi e metadati. Con la selezione cartella, il browser può prima raccogliere tutti i file: la profondità limita quelli inclusi nell’elenco. Il trascinamento dipende dal supporto del browser.

Elementi non leggibili

    2. Consulta e scarica

    Il download comprende tutti i risultati filtrati, non solo la pagina visibile. Date in UTC; il tipo MIME può non essere disponibile.
