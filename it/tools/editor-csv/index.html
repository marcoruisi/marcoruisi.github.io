Visualizza e modifica CSV

Visualizza e modifica celle, righe e colonne. Filtra i dati e dividi il CSV in più file per valore di una colonna. Tutto nel browser.

1. Apri un CSV

Trascina qui il CSV

Massimo 10 MB, 200 colonne e 300.000 celle. I valori restano testo: nessuna conversione automatica di codici, date o zeri iniziali. Le formule non vengono eseguite.

2. Modifica la tabella

Colonne e ordinamento

L’ordinamento agisce su tutte le righe e conserva l’intestazione. Le modifiche alla struttura delle colonne e Annulla/Ripristina azzerano i filtri per colonna.

Apri i filtri sotto il titolo di ogni colonna. I filtri si combinano con E: devono essere tutti soddisfatti. Non cancellano le righe. I confronti numerici usano il punto decimale.

Modifica direttamente una cella e poi esci dal campo per applicare. Intestazioni modificabili nella prima riga evidenziata. Le modifiche restano nella sessione finché scarichi il risultato.

3. Scarica o suddividi

Un CSV per ogni valore di una colonna

Esempio: scegli Città per ottenere un file per ogni città. Ogni file conserva le intestazioni, se attive. I valori vuoti formano un gruppo separato.

Il raggruppamento distingue maiuscole, minuscole e spazi. I nomi dei file hanno un prefisso numerico per evitare collisioni. Massimo 2.000 file per ZIP.
