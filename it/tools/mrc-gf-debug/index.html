MRC GF Debug

Diagnostica gli errori di validazione Gravity Forms senza attivare log permanenti.

Cosa fa

Mostra agli amministratori quali campi Gravity Forms falliscono la validazione direttamente sopra il form. Puoi limitare il debug a un solo form e, opzionalmente, mostrare il valore ricevuto.

I valori inviati sono disattivati per impostazione predefinita e non viene scritto alcun log permanente.

Requisiti

WordPress + Gravity Forms. Impostazioni in Strumenti → MRC GF Debug.

Installazione

In WordPress apri Plugin → Aggiungi plugin → Carica plugin, seleziona lo ZIP e attivalo.

Richiede Gravity Forms. Il pannello è riservato agli amministratori: non è un log persistente né una correzione automatica degli errori.
