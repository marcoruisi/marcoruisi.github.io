Unisci le tue immagini in un PDF

Scegli le foto, mettile nell’ordine giusto e scarica un unico PDF. Una foto per pagina, senza tagli.

Le immagini vengono elaborate solo nel tuo browser. Non vengono inviate a un server.

JPG, PNG e WebP. Puoi selezionare più foto o trascinarle qui.

      Scarica il PDF

      Il file è ancora troppo grande? Prova PDF Compressor →

      Il PDF usa pagine A4 con orientamento automatico. Le immagini molto grandi vengono ridotte per mantenere gestibile il file. Il testo nelle fotografie resta un’immagine: non viene riconosciuto né reso selezionabile. HEIC non è supportato in questa versione; esporta prima la foto in JPG.
