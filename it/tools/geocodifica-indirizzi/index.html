Geocodifica indirizzi

Da indirizzi a latitudine e longitudine. Output in due colonne pronto da incollare in Google Sheets.

Come vuoi cercare?

01 · Indirizzo singolo · API MRC

Tre ricerche immediate al giorno, poi brevi attese progressive. Un indirizzo alla volta. Nessun account necessario.

Ricerche immediate residue oggi: 3

La ricerca condivisa sarà disponibile dopo l’attivazione della chiave MRC. Nel frattempo puoi utilizzare la tua API gratuita.

02 · Lista di indirizzi · API personale

Incolla fino a 100 righe. Le richieste partono dal tuo browser e consumano soltanto la quota della tua chiave Geoapify.

Salvataggio facoltativo sul dispositivo, mai sui server MRC. La chiave rimane accessibile al browser: usa restrizioni per dominio e una chiave dedicata.

Come creare gratis la tua API (2 minuti)
  1. Apri Geoapify MyProjects e registrati gratuitamente.
  2. Crea un progetto e apri “API Keys”.
  3. Copia la chiave generata e incollala qui.
  4. Se usi soltanto MRC, limita la chiave al referrer/origine https://marcorui.si.
  5. Se vuoi, premi “Salva in questo browser”.

Non serve un account MRC. Controlla le condizioni del piano gratuito direttamente su Geoapify.

Risultato · due colonne

Le colonne sono separate da tabulazione. Righe vuote o non risolte restano in posizione. Incolla nella prima cella di Google Sheets.

Righe da controllare

    Perché una API personale per le liste?

    Per mantenere MRC gratuito per tutti, la ricerca condivisa è pensata per usi occasionali. Se elabori liste, puoi usare una tua chiave Geoapify gratuita, indipendente dalla quota degli altri utenti.

    Le ricerche avvengono nel tuo browser: MRC non riceve né archivia gli indirizzi. Gli indirizzi sono inviati a Geoapify per ottenere le coordinate. Risultati e chiave, se salvi la chiave, restano nella memoria locale del browser.

    Le coordinate sono indicazioni automatiche: verifica i risultati incerti prima di utilizzarli. Limite di 100 righe per esecuzione.
