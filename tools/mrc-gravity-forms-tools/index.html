MRC Gravity Forms Tools

A modular Gravity Forms toolkit for exports, form usage, tables and cards, autocomplete, frontend styles and image processing.

What it does

  • CSV and configurable export workflows for Gravity Forms entries.
  • Find where forms are used across WordPress content.
  • Generate tables and cards from entries with filters and pagination.
  • Google Places or Mapbox autocomplete with field mapping.
  • Frontend styling controls and local image-to-WebP processing.

ON REQUEST

This is a modular suite with configuration and visibility choices that should be reviewed for each site. It is not offered as an automatic download.
