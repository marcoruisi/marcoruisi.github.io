PDF Compressor

Set a maximum final file size and let the tool automatically adjust page resolution and image quality. Everything is processed locally in your browser.

To reliably hit a target size in the browser, pages are rasterized and rebuilt as image-based PDF pages. Text selection, links and vector objects are not preserved.

Your PDF is processed locally. The document is never uploaded.
