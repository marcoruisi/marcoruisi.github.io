Import all clues

Read clues from a photo (OCR)

The image is processed in your browser. The OCR engine and language data are downloaded on request. Read multiple photos or regions one at a time, appending text before applying it.

Drag on the photo to select the region to read. Without a selection, the whole image is read.

If a clue contains a spaced dash, choose “Only |” and use | only between different clues. Wrapped text lines are joined into the same clue.
