MRC GF Debug

Inspect Gravity Forms validation failures without enabling persistent logs.

What it does

Shows administrators which Gravity Forms fields fail validation directly above the form. Debugging can be limited to one form and submitted values can optionally be displayed.

Submitted values are off by default and no persistent log file is written.

Requirements

WordPress + Gravity Forms. Settings live under Tools → MRC GF Debug.

Installation

In WordPress, open Plugins → Add New → Upload Plugin, select the ZIP and activate it.

Requires Gravity Forms. The panel is for administrators: it is not a persistent log or an automatic error fix.
