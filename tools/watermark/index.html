Watermark

One watermark, many formats. Add text, a logo or a PDF page to images and documents. Everything stays in your browser.

Watermark settings

1. Add files

You can also drop files or folders here.

This selection applies to all PDFs. Override it for each file below. Numbers beyond the end are ignored; a PDF with no matching pages is not exported. Images are always watermarked.

2. Choose a watermark

You can also drop your watermark here.

Use a transparent PNG for a logo without a background. The PDF watermark is converted to an image; white areas drawn in the file remain white.

3. Position and size

X and Y locate the watermark centre, measured from the top-left corner. 50% / 50% = page centre.

Watermark proportions are preserved. Near the edges, its position is constrained to keep it entirely on the page; if too tall, it is scaled down.

4. Preview and apply

Preview a page before exporting.

Ready files

Download each file by its name or collect the results in a ZIP. PDFs retain their original pages: only the watermark is added. Images keep their pixel dimensions: JPEG to JPEG, PNG and WebP to PNG. Image metadata is not transferred.
