List files

List files in folders and subfolders with adjustable depth. Download paths, sizes and last modified dates as CSV or TXT.

1. Choose depth and folder

0 = files in the root folder only; 1 = also direct subfolders. After a change, select Scan again.

Drop a folder here

Reads names and metadata only. With the folder picker, your browser may collect all files first: depth limits those included in the list. Folder drag-and-drop depends on browser support.

Unreadable items

    2. Review and download

    Downloads include all filtered results, not just the visible page. Dates use UTC. Hidden files are those whose name, or a folder in their path, starts with a dot.
