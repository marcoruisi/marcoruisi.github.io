Click the map or import points. Up to 500 points per session.

Points (0)

    GIS data sources

    Vector · GeoJSON or zipped shapefile

    Point-in-polygon matching. If multiple geometries overlap, first matching attributes are used.

    GeoJSON in WGS84; shapefile ZIP requires a .prj for reprojection.

    Raster · local GeoTIFF

    Nearest pixel by band; standard affine georeferencing only.

    WMS · GetFeatureInfo

    Requires CORS, queryable layer and EPSG:4326 / WMS 1.1.1 support. WMS does not automatically provide source raster pixel values.

    Results (0)

    Exported shapefiles are WGS84 point geometries (EPSG:4326); DBF field names are limited to 10 characters.
