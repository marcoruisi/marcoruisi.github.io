Multiple Find & Replace

Replace multiple strings at once and clean up text, directly in your browser.

Your text stays in your browser: it is not sent to external servers.

Find / replace pairs

Strings are literal. Replacements apply to the original text: the longest string wins, then the first pair entered. Leave “Replace with” empty to delete a string.

Import / export pairs

UTF-8 CSV with two columns: find and replace. Import replaces the current pairs but does not process the text.


Text cleanup

Cleanup runs after replacement and works without pairs. Tabs are preserved; one blank line is kept between paragraphs.
