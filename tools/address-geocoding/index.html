How to create your free API key (2 minutes)
  1. Open Geoapify MyProjects and register for free.
  2. Create a project and open “API Keys”.
  3. Copy the generated key and paste it here.
  4. If you only use MRC, restrict the key to the https://marcorui.si origin/referrer.
  5. Optionally click “Save in this browser”.

No MRC account needed. Check the current free-plan terms on Geoapify.

    Why use a personal API key for lists?

    To keep MRC free for everyone, the shared lookup is intended for occasional use. For lists, use your own free Geoapify key, independently of other users’ quotas.

    Requests run in your browser: MRC does not receive or store addresses. Addresses are sent to Geoapify to retrieve coordinates. Results and your key, if you save it, are kept in local browser storage.

    Coordinates are automated suggestions: verify low-confidence results before using them. Limit of 100 rows per run.
