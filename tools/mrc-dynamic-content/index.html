MRC Dynamic Content

Use remote CSV data as dynamic Elementor content, with caching, language fallbacks and typed tags.

What it does

  • Configurable CSV sources with key column, delimiter and cache duration.
  • Dynamic Elementor tags for text, URL, number, colour and image.
  • WPML, Polylang or locale-based language fallback.
  • Manual source refresh and transient-based cache.

ON REQUEST

The current 0.1.4 build is an initial implementation. Dataset preview, autocomplete and AJAX selectors are not part of this version.

Requirements and use

Requires WordPress, Elementor and a reachable CSV source. Version 0.1.4 is an initial implementation, not a complete data-management interface.
