Gravity Forms Cards Directory

Turn approved Gravity Forms entries into a searchable, filterable card directory with categories, countries and AJAX pagination.

What it does

  • Reads active and approved Gravity Forms entries.
  • Category and country filters with ISO country normalisation.
  • AJAX pagination and lazy-loaded images.
  • Cards can include organisation, contacts, social links, photos, logos and badges.

ON REQUEST

The current 2.3 build uses a fixed field mapping. A public installation normally requires adapting that mapping to the target form.
