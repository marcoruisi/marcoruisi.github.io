TOOL · FREE · CSV, TSV, TXT → CSV, ZIP

View and edit CSV

View and edit cells, rows and columns. Filter data and split CSV files by column values. Everything stays in your browser.

1. Open a CSV

Drop your CSV here

Maximum 10 MB, 200 columns and 300,000 cells. Values stay as text: no automatic conversion of codes, dates or leading zeros. Formulas are not executed.

2. Search and filter

Filters are combined with AND: all conditions must match. They do not delete rows. Numeric comparisons use a decimal point.

3. Edit the table

Columns and sorting

Sorting applies to all rows and keeps the header. Column structure changes and Undo/Redo clear column filters.

Edit a cell and leave the field to apply. Edit headers in the highlighted first row. Changes stay in this session until you download the result.

4. Download or split

One CSV per column value

Example: choose City to get one file per city. Each file retains headers when enabled. Empty values form a separate group.

Grouping distinguishes case and spaces. Filenames have a numeric prefix to avoid collisions. Maximum 2,000 files per ZIP.
