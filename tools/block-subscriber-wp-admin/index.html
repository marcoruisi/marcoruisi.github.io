Block Subscriber access to wp-admin

Users need to log in, but not access the dashboard? This snippet redirects Subscribers to the homepage when they try to open /wp-admin/.

The code

AJAX requests continue to work normally. Users who can edit content are not blocked, even if they also have the Subscriber role.

PHP · WordPress · Code Snippets compatible
/**
 * Redirect WordPress Subscribers away from wp-admin.
 */
add_action( 'admin_init', function () {
    if ( wp_doing_ajax() ) {
        return;
    }

    $user = wp_get_current_user();

    if ( ! $user || ! $user->exists() ) {
        return;
    }

    $is_subscriber = in_array( 'subscriber', (array) $user->roles, true );
    $can_edit = current_user_can( 'edit_posts' );

    if ( $is_subscriber && ! $can_edit ) {
        wp_safe_redirect( home_url( '/' ) );
        exit;
    }
} );

How to use it

  1. Install the free Code Snippets plugin on WordPress.
  2. Create a new PHP snippet.
  3. Copy and paste the code above.
  4. Set it to Run snippet everywhere and activate it.

Code Snippets is the recommended method because it makes the snippet easy to enable and disable. If you already know where to put it, you can integrate the same PHP into your WordPress code.

Note. This snippet keeps Subscribers out of the admin area. It does not replace WordPress permissions and does not protect content or files that are otherwise publicly accessible.
