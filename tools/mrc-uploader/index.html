MRC Uploader

A WordPress admin utility for managing files under uploads, importing CSV data and editing source files with backups.

What it does

  • Create and manage folders and files inside the WordPress uploads area.
  • Upload, rename, delete and mark favourite files.
  • Import single or multiple CSV files and read rows from a Google Sheet source.
  • Built-in file editor with backup and atomic replacement.

ON REQUEST

Because it writes to the filesystem and includes administrative operations, permissions and path confinement must be reviewed for the target installation.

Requirements and use

Requires WordPress administrator permissions. Review capabilities, allowed paths and backups on the destination site before enabling filesystem operations.
