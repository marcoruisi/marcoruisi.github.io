Tool Flows

One tool solves a problem. Its result can become the starting point for another.

Three ideas to get started

01

From Word to custom HTML

Clean up a formatted document, then edit the HTML with multiple replacements.

  1. Input · StartWord documentHeadings, bold text, lists
  2. →↓ToolHTML Editor ↗Clean and copy the code
  3. →↓ToolMultiple Find & Replace ↗Apply changes in bulk
  4. →↓
    Output · ResultCustom HTMLReady to reuse

To keep headings, bold text and lists, transfer the HTML code, not the rendered text.

02

From images to a lighter PDF

Reduce image file sizes before bringing them together in one document.

  1. Input · StartImagesPhotos and scans
  2. →↓ToolImage to Target Size ↗Make the files smaller
  3. →↓ToolImages to PDF ↗Bring the images together
  4. →↓
    Output · ResultLighter PDFReady to share
03

From a print PDF to a web-ready PDF

Remove bleed and crop marks, then reduce the document’s file size.

  1. Input · StartPrint PDFWith bleed and crop marks
  2. →↓ToolPrint PDF to Web ↗Crop the page
  3. →↓ToolPDF Compressor ↗Reduce the file size
  4. →↓
    Output · ResultWeb-ready PDFReady to send

The connections are yours to find

The most useful flow might be one we haven’t imagined.

These are just three examples, not fixed routes. Each tool works on its own, but you can connect them and carry on with tools from elsewhere. Choose the combinations that suit what you need to achieve.

Copy and paste, or a downloaded file, may be all you need. Check the format required by the next step: not every result fits every tool.
